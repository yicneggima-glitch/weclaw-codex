WeClaw Codex v0.7.1
一款将微信连接到 Codex 的 macOS 工具。
功能
- 微信消息接入 Codex
- Codex 对话列表与切换
- 本机对话记录显示
- 文件接收与发送
- 菜单栏后台运行
- 同步登录与退出登录
- Apple 风格界面
- 自动配置工作目录和 Codex 通道
使用环境
- macOS 13+
- Apple Silicon 芯片
- 首次启动需要微信扫码登录
